# Латинський словник

Латинсько-українсько-англійський словник медичної термінології.

**Джерело даних — один файл `dictionary.xlsx`.** Змінили його й завантажили на GitHub — сайт оновиться сам за 1–2 хвилини.

## Зв'язки між гаслами

Колонки `Синоніми` і `Антоніми` містять інші гасла словника (через «;»). Зв'язок вносять з обох боків. Після кожної збірки перегляньте звіт у журналі Actions: він показує висячі, неоднозначні й односторонні посилання.

## Джерела

Колонка `Джерело` містить номер джерела гасла; самі джерела (назва, хто надав слова, посилання) — на аркуші `Джерела`. Вони видимі на сторінці «Про словник» і на сторінці кожного гасла.

## Структура

| Файл / папка | Що це |
|---|---|
| `dictionary.xlsx` | Словник (редагується вручну). Правила заповнення — на аркуші «Як заповнювати» |
| `build.py` | Перетворює Excel на `site/data.js`. Запускати вручну не потрібно |
| `site/` | Сам сайт (HTML, CSS, JS, шрифти) |
| `.github/workflows/deploy.yml` | Автоматична збірка й публікація на GitHub Pages |

## Локальна перевірка (необов'язково)

```
pip install openpyxl
python build.py
```
Потім відкрити `site/index.html` у браузері.

Шрифти: Spectral та IBM Plex Sans (SIL Open Font License, ліцензії — у `site/fonts/`).
